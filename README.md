# ХАТА.ON

Адаптивний магазин рішень для тепла, світла, зв’язку та автономності під час відключень.

**Основний сайт:** https://hata-on.pages.dev/

**Резервна адреса:** https://pikushkristina-art.github.io/hata-on/

## Що працює

- головна сторінка з категоріями, готовими наборами та хітами;
- підбір набору за тривалістю відключення;
- кошик зі збереженням на пристрої;
- форма оформлення;
- формування, копіювання та поширення тексту замовлення;
- адаптивна версія для телефону, планшета й комп’ютера.

Сайт статичний і не потребує платного сервера або бази даних. Ціни та наявність мають підтверджуватися перед оформленням реального продажу.

Перед прийманням замовлень додайте Telegram, телефон або email продавця у `store-config.js`.
