# ХАТА.ON

Мобільний MVP-магазин рішень для тепла, світла, зв'язку та автономності під час відключень.

## Що працює

- адаптивний каталог і фільтри;
- кошик зі збереженням на пристрої;
- готовий набір «Теплий вечір»;
- форма оформлення;
- формування, копіювання та поширення тексту замовлення.

Сайт статичний і не потребує платного сервера або бази даних.

Перед прийманням реальних замовлень додайте Telegram, телефон або email продавця у `store-config.js`.
